# TG6 채용 사이트 — 사용 가이드

> 모바일 우선, PC에서도 휴대폰 프레임으로 보이는 TG6 봉제공장 채용 랜딩 페이지

---

## 📁 폴더 구조

```
tg6-recruit/
├── index.html        ← 메인 HTML (모든 섹션 포함)
├── css/
│   └── style.css     ← 모든 스타일
├── js/
│   └── script.js     ← 탭 인터랙션, 시계, 수입 카드 클릭
└── images/           ← 사진 폴더 (아래 가이드 참고)
```

---

## 🎨 색상 / 디자인 변경

`css/style.css` 파일 맨 위 `:root` 섹션에서 색상을 한 번에 변경 가능:

```css
:root {
  --orange: #f57e2c;       /* 주 강조색 */
  --green: #2d8659;        /* 카드 제목 */
  --dark-bg: #0a3d28;      /* 영웅 영역 배경 오버레이 */
  --navy-2: #0e1d3c;       /* 수입 섹션 배경 */
}
```

## 🚀 배포 방법

### 옵션 1: Netlify (현재 사용 중인 방식)
1. `tg6-recruit` 폴더 전체를 `G:\내 드라이브\claude\tg6-recruit\`에 업로드
2. Netlify가 자동으로 동기화 → `tg6-xuongvui.netlify.app`에 반영

### 옵션 2: 미리보기
폴더 안의 `index.html`을 더블클릭하면 브라우저에서 바로 확인 가능
